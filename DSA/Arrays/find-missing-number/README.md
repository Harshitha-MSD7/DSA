## 📝 Problem Statement

Given an integer array of size n containing distinct values in the range from **0 to n (inclusive)** , return the only number missing from the array within this range.

### Example 1

<p>

**Input:** nums = [0, 2, 3, 1, 4]</p><p>

**Output:** 5</p><p>

**Explanation:** </p>nums contains 0, 1, 2, 3, 4 thus leaving 5 as the only missing number in the range [0, 5]

### Example 2

<p>

**Input:** nums = [0, 1, 2, 4, 5, 6]</p><p>

**Output:** 3</p><p>

**Explanation:** </p>nums contains 0, 1, 2, 4, 5, 6 thus leaving 3 as the only missing number in the range [0, 6]

### Constraints

- n == nums.length
- 1 <= n <= 10^4
- 0 <= nums[i] <= n
- All the numbers of nums are unique.

---

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
